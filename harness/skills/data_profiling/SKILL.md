# 数据探查 SOP

在任何清洗或分析之前，先回答清楚以下问题，不要跳过探查直接假设字段含义。

1. **规模**：行数、列数、内存/文件大小；判断是否需要分块或大数据方案。
2. **字段构成**：每列的实际 dtype 与语义类型（数值/类别/日期/ID/文本）；
   警惕"数字存成文本""日期存成字符串""ID 前导零丢失"。
3. **缺失**：每列缺失率与缺失模式；标记全空列、近全空列。
4. **唯一性与重复**：主键/ID 是否唯一，是否存在整行重复。
5. **分布与哨兵值**：数值列 min/max/分位数；识别 -999、9999、"N/A"、空格等
   伪缺失哨兵；类别列的取值清单与拼写不一致（大小写、空格、近义词）。
6. **风险清单**：按 高/中/低 输出问题列与处理建议，作为清洗规则的依据。

纪律：探查结论以工具真实输出为准；样本（head/tail/随机抽样）只能辅助判断，
不能用前几行代替全量统计。完整画像写入数据资产，正文只引用结论与路径。
