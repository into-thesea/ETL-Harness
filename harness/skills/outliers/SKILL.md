# 异常值处理 SOP

异常值可能是数据错误，也可能是真实的重要信号，先甄别再处理。

1. **识别（建议两种方法互证）**
   - IQR 法：超出 [Q1−1.5·IQR, Q3+1.5·IQR] 标记，偏态分布首选；
   - Z-score：|z|>3（近似正态时）；样本量小或非正态时不可靠；
   - 结合业务上下限（如金额不可能为负、年龄有合理区间）。
2. **甄别成因**：录入错误/单位错误（元 vs 元）/重复/真实稀有事件。
3. **处理优先级**
   - 能确认是错误且可纠正 → 纠正；
   - 不能删除但需削弱影响 → **盖帽法(clip/winsorize)** 到分位数边界，保留行数；
   - 确认为错误且无法修正 → 剔除并记录；
   - 真实业务极值（大额订单等）→ **保留**，在分析中单独说明，必要时分桶/对数变换。
4. 时序数据先确认是否为节假日/活动导致的"预期异常"，避免误删。
5. 处理前后对比分布，报告受影响行数与方法，不静默丢数据。
