# 报告排版 SOP

报告面向决策，先给结论，再给支撑；每个关键结论都能追溯到数据。

1. **标准结构**
   - 摘要（Executive Summary）：1 段话讲清背景、最关键结论与建议；
   - 核心指标：关键 KPI 的数值、同环比、目标达成；
   - 分析与归因：现象 → 拆解 → 原因，配必要图表；
   - 风险与不确定性：数据口径、样本局限、未覆盖项；
   - 结论与建议：可执行、分优先级，明确预期效果。
2. **可溯源**：结论数字来自真实工具结果，正文、图表、SQL 口径一致；
   引用上游结论而非凭空生成。
3. **表达**：结论先行、数据说话、避免无依据的断言；区分"事实 / 推断 / 建议"。
4. 关键指标注明口径与时间范围；存在多种合理解释时并列呈现，不武断归一。
5. 报告与图表产物落盘归档，便于复核与复用。
