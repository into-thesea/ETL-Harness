<a id="辛普森悖论案例"></a>
## 辛普森悖论案例

### 场景描述
某电商平台 2026 年 9 月整体转化率从 5.0% 上升到 5.2%，看似在改善。但按渠道拆分后，发现移动端转化率从 4.5% 下降到 4.3%，PC 端转化率从 6.0% 下降到 5.8%。整体上升只是由于高转化的 PC 端流量占比从 30% 下降到 20%，低转化的移动端占比上升所致。

### 错误结论
```text
整体转化率提升 0.2 个百分点，各渠道运营策略有效。
```
**问题**：忽略了流量结构变化带来的辛普森悖论，把结构效应误认为是真实改善。

### 正确做法
先按渠道分组计算转化率，再检查整体趋势与分组趋势是否矛盾。

```sql
-- 分组计算转化率
WITH channel_stats AS (
    SELECT
        channel,
        SUM(visits) AS visits,
        SUM(conversions) AS conversions,
        SUM(conversions) * 1.0 / SUM(visits) AS cvr
    FROM traffic
    WHERE dt BETWEEN '2026-09-01' AND '2026-09-30'
    GROUP BY channel
)
SELECT channel, visits, conversions, cvr FROM channel_stats;
```

### 正确输出
```text
归因结论：整体转化率从 5.0% 上升至 5.2%，但各渠道均下降（辛普森悖论）
主要驱动维度：流量结构变化，移动端占比从 70% 上升至 80%，贡献度 100%
次要驱动维度：无（各渠道内部转化率均下降，不存在正向驱动）
数据支撑：/workspace/reports/cvr_channel_20260930.sql
风险提示：整体趋势与分组趋势方向相反，属辛普森悖论。禁止使用“整体转化率提升”作为结论，应改为“各渠道转化率均下降，整体上升系流量结构变化所致”。
```

### 自检清单
- [x] 已按渠道分组计算转化率
- [x] 已对比整体趋势与分组趋势
- [x] 已识别结构效应并量化贡献度
- [x] 已在输出中明确提示辛普森悖论风险

### 注意事项
1. **分组维度要覆盖主要结构变化**：渠道、新老用户、地域、设备类型等常见维度都应检查。
2. **贡献度分解时区分“结构效应”与“内部效应”**：结构效应是各组占比变化导致，内部效应是各组自身指标变化导致。
3. **禁止只看整体不看分组**：所有涉及比率指标的归因，必须做分组校验。

<a id="量价分解输出示例"></a>
## 量价分解输出示例

### 场景描述
某零售企业 2026 年 9 月 GMV 从 1.2 亿下降到 1.1 亿，需要判断是“销量下降”还是“单价下降”导致。

### 分析流程
1. 获取本期和基期的销量、均价、GMV。
2. 量效应 = （本期量 - 基期量）× 基期价。
3. 价效应 = （本期价 - 基期价）× 本期量。
4. 验证：量效应 + 价效应 ≈ GMV 变化总量。

```sql
-- 量价分解
WITH base AS (
    SELECT SUM(qty) AS qty, SUM(gmv) / SUM(qty) AS price, SUM(gmv) AS gmv
    FROM sales WHERE dt BETWEEN '2026-08-01' AND '2026-08-31'
),
curr AS (
    SELECT SUM(qty) AS qty, SUM(gmv) / SUM(qty) AS price, SUM(gmv) AS gmv
    FROM sales WHERE dt BETWEEN '2026-09-01' AND '2026-09-30'
)
SELECT
    curr.qty - base.qty AS qty_change,
    curr.price - base.price AS price_change,
    (curr.qty - base.qty) * base.price AS volume_effect,
    (curr.price - base.price) * curr.qty AS price_effect,
    curr.gmv - base.gmv AS total_change
FROM base, curr;
```

### 正确输出
```text
归因结论：GMV在2026-09-01至2026-09-30期间下降1000万（-8.3%）
主要驱动维度：销量下降，量效应 -1200万，贡献度 120%
次要驱动维度：单价上升，价效应 +200万，贡献度 -20%
数据支撑：/workspace/reports/price_volume_20260930.sql
风险提示：量效应与价效应方向相反，说明销量下降的同时单价上升，需警惕是否为提价导致的销量下滑。建议结合价格弹性分析进一步验证。
```

### 自检清单
- [x] 已获取本期和基期的销量与均价
- [x] 已计算量效应和价效应
- [x] 已验证量效应 + 价效应 ≈ 总变化
- [x] 已识别量价方向是否一致，并在风险提示中说明

### 注意事项
1. **量价分解适用于收入类指标**：GMV、销售额、营收等。不适用的场景（如用户数、转化率）不要强行套用。
2. **量效应与价效应可能方向相反**：例如提价导致销量下降，此时二者符号相反，需要在风险提示中说明。
3. **不要在量价分解中混入结构效应**：如果产品结构发生变化，需要先按品类分解，再在各品类内部做量价分解。

<a id="归因逻辑反例"></a>
## 归因逻辑反例

### 反例 1：把相关当因果
**场景**：发现“页面改版后用户流失率上升”，直接得出结论“页面改版导致用户流失”。
**问题**：页面改版与用户流失可能同时发生，但未必存在因果关系。可能同期还有大促结束、竞品上线、季节性因素等。
**正确做法**：如果要论证因果，需要排除其他解释，或使用 A/B 实验、断点回归、双重差分等因果推断方法。如果无法排除，改为相关性描述：“页面改版与用户流失率上升同期出现，建议进一步验证”。

### 反例 2：忽略辛普森悖论
**场景**：整体客单价上升，直接得出结论“用户消费能力提升”。
**问题**：可能是高消费用户占比上升，而各消费层级的客单价均下降。
**正确做法**：按消费层级分组，检查各分组内客单价变化，再看整体变化是否由结构变化驱动。

### 反例 3：混淆绝对量与相对量
**场景**：A 渠道增长 100 单，B 渠道增长 50 单，得出结论“A 渠道贡献更大”。
**问题**：如果 A 渠道基数是 10000 单，B 渠道基数是 100 单，A 渠道增长率仅 1%，B 渠道增长率高达 50%。绝对贡献大不代表相对贡献大。
**正确做法**：同时报告绝对量和相对量，根据用户关注的角度选择口径。

### 反例 4：维度拆分不穷尽
**场景**：按地域拆解后贡献度合计仅 60%，剩余 40% 未解释。
**问题**：说明还有未纳入分析的维度在起作用，或者维度之间交叉重叠导致贡献度无法简单相加。
**正确做法**：检查维度是否覆盖完整，必要时引入更多维度（如渠道、用户层级），或使用 MECE 原则确保各维度互斥且穷尽。

### 反例 5：贡献度计算错误
**场景**：某维度变化 +10 万，总变化 -5 万，计算出贡献度 -200%。
**问题**：虽然数学上成立，但贡献度绝对值超过 100% 说明存在多个方向相反的驱动因素。此时应同时列出所有主要维度，并说明方向。
**正确做法**：列出所有主要驱动维度（含正向和负向），说明各自的贡献度和方向，不要只报告贡献度最高的一个。
