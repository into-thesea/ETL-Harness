# 数据质量门

## 概述
定义数据质量的红线规则。在分析流程入口（数据获取后、清洗前）执行强制校验。本 Skill 优先级高于分析类 Skill，触发红线时立即阻断并通知用户。数据质量门是分析可信度的第一道防线，宁可不分析，也不能用脏数据得出结论。

## 强制红线规则（触发即阻断）
1. **关键字段缺失率超标**：任何关键字段（主键、时间戳、核心指标）缺失率 > 30%，直接阻断，返回字段名和缺失率。
2. **行数波动超标**：与上次成功加载的同一数据源相比，行数波动 > ±20%，直接阻断，返回上次行数、当前行数和波动比例。
3. **主键重复**：主键存在重复值，直接阻断，返回重复行数和重复样本（最多展示 5 条）。
4. **关键字段全空**：任何关键字段 100% 为空（null 或空字符串），直接阻断，返回字段名，提示“上游数据生产中断或字段映射错误”。

## 警告规则（非阻断，但须标记）
- **时效性超期**：日更数据最新时间戳距今超过 2 天，周更超过 10 天，标记“数据可能过期”，在报告中注明。
- **类别值异常**：分类字段的类别数量变化超过 20%，标记“类别结构漂移”，建议人工确认。
- **数值范围异常**：出现负数年龄、超 150 岁等不合理值，标记“数值范围异常”，交由清洗阶段处理。

## 输出契约
必须严格按照以下结构输出，不得增删字段：
```text
数据质量门校验结果：{通过 / 阻断 / 警告}
触发规则：{规则编号} - {规则名称}
问题详情：{具体数值与阈值对比}
建议动作：{阻断时需说明排查方向；警告时需说明标注要求}
```

## 核心示例
**输入**：数据探查发现 `customer_id` 缺失率 35%，`age` 存在 47 个超出范围值。
**输出**：
```text
数据质量门校验结果：阻断
触发规则：R1 - 关键字段缺失率超标
问题详情：customer_id 缺失率 35%，超过 30% 阈值
建议动作：请检查上游 ETL 是否正常，修复缺失后再进入清洗流程。age 字段范围异常（47个）暂不阻断，将在清洗阶段交由 outliers Skill 处理。
```
