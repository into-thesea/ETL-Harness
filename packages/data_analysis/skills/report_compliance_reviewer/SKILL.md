# 报告合规审查

## 概述
作为独立的“审查者”角色，在报告产出前进行终审。与 `report_structure` Skill 形成“构建者-审查者”分离：`report_structure` 负责生成报告，本 Skill 负责质疑和验证。**构建者绝不能审批自己的工作**。审查不通过时，报告退回至报告撰写环节修改。

## 强制审查清单
1. **C1 数据溯源**：报告中每一个数据结论必须能追溯到 VFS 中的真实文件。审查方式：从报告中提取所有数字，逐一检查是否有对应的数据文件路径引用。如果某数字无法溯源，标记为“不可溯源”。
2. **C2 数字一致性**：报告中同一指标在不同位置（正文、图表、摘要、结论）的数值必须一致。不一致时，以 VFS 原始文件中的数值为准，标记差异位置。
3. **C3 PII 残留**：扫描报告全文（含图表标题、数据标签、备注文字），检查是否存在未脱敏的身份证号、手机号、银行卡号、完整姓名。**发现时立即阻断发布**。
4. **C4 结论支撑度**：对每一条结论评估其是否被数据支撑：
   - **充分支撑**：结论有明确的统计证据（p 值、置信区间、贡献度分解）
   - **部分支撑**：结论方向正确但缺乏量化证据
   - **过度解读**：结论超出数据范围（如用相关性推断因果）
   标记为“过度解读”的结论，必须退回修改。
5. **C5 风险提示完整性**：检查报告是否包含了必要的风险提示：数据质量警告（如缺失率、数据过期）、分析局限性说明（如样本偏差、假设条件）、辛普森悖论风险提示（如存在）。

## 输出契约
必须严格按照以下结构输出，不得增删字段：
```text
╔══════════════════════════════════════════════╗
║ 报告合规审查 — {报告名称}                     ║
╠══════════════════════════════════════════════╣
║ 溯源校验     {✓/⚠} {X}/{Y} 数字可溯源         ║
║ 一致性       {✓/⚠} {问题描述}                ║
║ PII 扫描     {✓/✗} {问题描述}                ║
║ 结论支撑     {✓/⚠} {问题描述}                ║
║ 风险提示     {✓/⚠} {问题描述}                ║
╠══════════════════════════════════════════════╣
║ 结论：{Accepted / Needs Revision / Blocked}   ║
║ 待修复项：{逐条列出}                          ║
╚══════════════════════════════════════════════╝
```

## 审查结论定义

| 结论 | 条件 | 后续动作 |
|---|---|---|
| **Accepted** | 全部检查通过 | 报告可发布 |
| **Needs Revision** | 存在可修复的问题 | 返回修改，附具体问题清单 |
| **Blocked** | 存在不可修复的问题（如 PII 残留、数据不可溯源） | 阻断发布，升级至人工处理 |

## 核心示例
**输入**：一份包含“GMV 1.23亿”的报告，但 VFS 文件显示 1.24亿，且正文称“用户流失与页面改版有关”但无统计证据。
**输出**：
```text
╔══════════════════════════════════════════════╗
║ 报告合规审查 — 华东区周报                     ║
╠══════════════════════════════════════════════╣
║ 溯源校验     ✓ 12/12 数字可溯源               ║
║ 一致性       ⚠ 1 处不一致（摘要 1.23亿 vs 正文 1.24亿）║
║ PII 扫描     ✓ 无残留                         ║
║ 结论支撑     ⚠ 1 条结论标记为“过度解读”        ║
║ 风险提示     ✓ 已包含                         ║
╠══════════════════════════════════════════════╣
║ 结论：Needs Revision                          ║
║ 待修复项：                                    ║
║   1. 摘要中 GMV 为 1.23 亿，正文为 1.24 亿，以 VFS 为准修改摘要。
║   2. “用户流失与页面改版有关”缺乏统计证据（无 p 值/置信区间），退回修改，改为相关性描述或补充检验。
╚══════════════════════════════════════════════╝
```
