# 图表选择 SOP

先确定"要回答什么问题"，再选图；一张图只表达一个核心信息。

1. **按目的选图**
   - 时间趋势 / 变化 → 折线图；
   - 类别对比 / 排行 → 柱状图（类目长用横向条形）；
   - 部分占整体比例（类别少）→ 饼图/环形；类别多 → 改用柱状；
   - 分布 → 直方图 / 箱线图；
   - 两变量关系 / 聚类 → 散点图；
   - 多维评估 → 雷达图；流程转化 → 漏斗。
2. **数据纪律**：坐标轴单位与标签正确、连续数据不随意排序造成错位、缺值显式标注；
   同一指标在多张图口径一致。
3. **避免误导**：不滥用 3D、不随意截断纵轴夸大幅度、不轻易双 Y 轴（必须用时
   清晰标注两条轴与对应系列）；颜色不是唯一区分手段，配合标签/图例。
4. 类别过多、过密时聚合 TopN + 其他，或拆图，不靠不可读小字硬塞。
5. 图表标题写明对象、指标、时间范围；产物落盘并在报告中引用。
