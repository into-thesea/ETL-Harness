# 缺失值处理 SOP

先判断**为什么缺**，再决定怎么处理；缺失本身可能携带信息。

1. **定位缺失机制**
   - 完全随机缺失(MCAR)：缺失与任何值无关；
   - 与其他字段相关(MAR)、与自身未观测值相关(MNAR)：缺失有规律，需在报告中说明。
2. **按字段选择处理**
   - 数值列、近似对称、MCAR → 均值；偏态或有极端值 → **中位数**更稳健；
   - 类别列 → 众数，或显式类别 "Unknown"（保留"缺失"这一信息）；
   - 时间序列 → 前向/后向填充、线性或时间插值，勿用未来数据泄漏填充；
   - 高缺失率列（如 >60%）→ 评估整列剔除，但须记录，不静默删除。
3. **禁止**：对 ID/主键填充；对目标(label)用特征信息"猜填"造成数据泄漏；
   不看分布就统一均值填充。
4. 填充后复核缺失率，并在清洗报告中写明每列用了什么策略、影响多少行。
