### 5.2 ① 的收尾（**卡在这里，需决策**）

接线已完成并**经诊断验证有效**（900 字符观察值 → 沉淀到虚拟文件、提示缩短到 331 字符）。

但**真实 LLM 实测暴露两个问题**：

1. **零沉淀** —— 66 次工具调用、一次都没触发沉淀。原因：**内置工具自身已有"长结果落盘、只回摘要"的设计**，回给内核的文本都在阈值以内。→ **`sink_threshold_chars=500` 在当前工具集下几乎是死代码**，其价值场景是"工具真的返回长文本时"（如代码执行的 stdout 上限 3000、将来的自定义工具）。
2. **压缩是否触发无观测手段** —— 它不打日志、没有计数，只能从步数推断（`chartist` 跑 8 步，应该触发过）。

→ **建议**：给上下文管理器加**轻量统计计数**（沉淀次数、压缩次数、被折叠消息数、压缩前后字符量），再跑一轮取真实数据。**加了才能判断阈值该不该调**（用户既定策略：接线后拿实测数据再调）。

### 6.3 本项目踩过的坑

**本轮新增的完整清单见 `docs/遇到过的问题.md`（18 项）**，其中值得优先记住的：

- **配置类**：配置框架的 env 文件机制**不向下传播到嵌套模型** —— 症状是"改了配置文件没用且不报错"，修复方式是在实例化配置前显式载入
- **沙箱类**：官方服务端某版本**打包漏了协议模块**（装不起来）→ 锁旧版本 + 独立环境；命令须传字符串；镜像无工作目录；超时判定不能依赖完成事件
- **协议类**：编排框架的内部消息形态与服务商契约不一致（工具调用条目）；MCP 客户端侧字段是下划线风格、按驼峰取会**静默退化**；MCP 把正常返回一律视为成功
- **上下文类**：按条压缩会**切断工具调用配对**，只在长任务发作；两个视图（原始历史 / 本次提示）不要搞成两份状态
- **通用**：**不报错的错最贵**；只在长任务发作的缺陷短测试测不出；"有模块"≠"生效"

### 6.4 沿用上一份的环境坑

- PowerShell 先设 `$env:PYTHONIOENCODING="utf-8"`；用 `-m tests._xxx`
- pandas 3.x / numpy 2.x：文本列 dtype 可能是 `string` 而非 `object`；`df.append`/`iteritems`/`np.NaN` 已移除；写 CSV 给 Excel 用 `utf-8-sig`
- 代码执行工具限流 5/分钟：测试里连续走 Broker 会触发限流，handler 级测试直接调工具函数绕过
